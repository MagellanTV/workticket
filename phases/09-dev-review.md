# Phase 09 — Developer Review `GATED + LOOP`

## Confidence routing

| Score | Presentation |
|---|---|
| HIGH | `git diff --stat` + 1-sentence summary |
| MEDIUM | Per-file diff with brief notes |
| LOW | Full walkthrough + AC mapping |

## Developer response routing

| Response | Action |
|---|---|
| Approval | Exit loop -> Phase 10 |
| "Fix {detail}" | Fix, re-validate Phase 08, stay in loop |
| "Wrong approach" | Re-enter Phase 05 with feedback |
| "Change the plan" | Re-enter Phase 06 with new context |
| New requirements | Update ticket data, re-enter Phase 06 |

On re-entry: report clearly which phase and why.
